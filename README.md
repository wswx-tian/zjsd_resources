# 应急保障资源一张网

独立的主页设计原型，保留原目录中的物流仿真演示。

双击 `dist/index.html` 即可打开，必须保留整个 `dist` 目录。推荐 Edge 或 Chrome；概览卫星瓦片、行政边界和数据均在本地。深入缩放与简洁底图需要网络。

也可在本目录执行 `node server.cjs`，访问 `http://127.0.0.1:4188/`。

页面读取 5 类最新业务数据，展示 1,844 个仓点、35,517 条物资明细、1,441 支应急队伍区域统计、117 个运输机构和 280 条装备记录。队伍表只有区域汇总，页面不再保留旧版单支队伍属性；系统合计比已显示区域小计多 1 支，差额未分配到区域。运输机构使用合并表字段，联系方式仅在来源有值时显示。测试仓点已剔除；未归属区县的 10 个仓点保留在地图和台账中。仓库与物资按来源仓库名称关联。数据口径和缺少的指标见 `产品与架构设计.md`。

主要交互：按仓库级别逐层呈现的地图点位与辖区网络连线、队伍数量区县着色、区县下钻、资源详情、仓库物资关联、区域/关键词联动、单资源类型切换、资源台账分类/分页、CSV 导出和底图切换。资源台账只通过上方搜索框右侧的独立按钮进入；侧栏与统计卡片没有进入台账的入口。按 `/` 聚焦搜索。台账可通过右上角“返回地图”、再次点击独立入口或 Escape 收起；Escape 按弹窗、资源详情、台账的顺序逐层关闭。

页面是这 5 份表格形成的静态数据快照，不代表业务系统实时同步，也不用于实际调度。

浏览器交互核验：先启动本地服务，再执行 `node verify.cjs` 和 `node verify-interactions.cjs`。本地需要已安装 Chrome 或 Edge，不依赖额外 npm 包。
